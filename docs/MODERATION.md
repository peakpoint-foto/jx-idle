# O03 — moderation online (đang thực hiện)

Migration `0008_player_moderation.sql` thêm block, report và admin audit tables; `0009_player_mutes.sql` thêm mute có hạn. `/api/moderation` chỉ nhận tài khoản online CTC đã xác thực; report giới hạn lý do allowlist, chi tiết tối đa 500 ký tự và 5 report/ngày; block tự loại friendship/lời mời đang chờ. Friend request/accept và room invite/accept kiểm tra block ở Worker. Mute 1 giờ/1 ngày/7 ngày ẩn invite, không xóa bạn đã chấp nhận. Chưa có chat room/bang; nếu thêm chat, phải áp dụng mute/block trước khi mở luồng gửi.

`/api/admin/moderation` đọc report và đổi trạng thái `open/reviewing/closed`; yêu cầu `x-admin-key` khớp Worker secret `ADMIN_KEY` và rate limit 120 request/phút. UI trong tab Khác yêu cầu admin nhập khóa theo phiên; không lưu khóa trong localStorage/save, render nội dung báo cáo bằng `textContent`, và không gửi qua webhook. Mỗi lần admin đổi trạng thái report tạo bản ghi audit chỉ gồm action, target và report ID.

Report bị giới hạn 5 lần/người chơi/24 giờ; report lưu tối đa 180 ngày, audit tối đa 365 ngày. UI bạn bè có block/mute/report; admin review render text bằng textContent. D1 local kiểm tra report trùng/cap, mute ẩn invite và vẫn cho bạn đã chấp nhận, block ngăn friend, sai admin key, audit status. Còn thiếu điều tra report abuse/private-data review và danh tính admin riêng (hiện dùng một secret chung); O03 chưa nghiệm thu và online public chưa được mở.
