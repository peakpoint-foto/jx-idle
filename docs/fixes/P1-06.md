# P1-06 — offline gains

ID / trạng thái: code/test local; cần manual clock/write failure trên browser thật

Đã thực thi:

- Giữ mốc tối thiểu 60 giây, giới hạn mỗi lần 8 giờ và quota ngày 12 giờ theo luật hiện tại.
- Regression kiểm tra 59/60 giây, 1 phút có XP và trường hợp quota còn 4 giờ sau cửa sổ 20 giờ.
- Chạy offline gains qua fixture đồng hồ cố định, không mở rộng phần thưởng hoặc multiplier ngoài luật hiện hành.

Chưa đóng: kiểm tra browser với đồng hồ lùi/tiến, localStorage write failure, nhận thưởng rồi reload và hai tab; đây là các ca cần fixture browser hoặc thiết bị thật.
