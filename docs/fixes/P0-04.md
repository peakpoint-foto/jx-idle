# P0-04 — API claim và replay

ID / trạng thái: hardening code xong; chưa đạt server-authoritative combat

Đã thực thi:

- Claim kiểm tra activity, event key, contribution/cleared theo cap riêng từng hoạt động.
- Reuse event key khác activity bị từ chối; retry cùng activity trả contribution/cleared/won ban đầu.
- Quota insert có điều kiện theo account/activity/UTC period và unique key.
- Client run ID chỉ dùng idempotency; ledger không được coi là bằng chứng combat server-authoritative.

Giới hạn bắt buộc: kết quả combat hiện vẫn được client báo cáo, server chưa cấp run ticket trước start và chưa tự mô phỏng/đối chiếu từng wave. Vì vậy không tuyên bố chống gian lận tuyệt đối; điểm/thưởng online thực sự cần bước thiết kế server-authoritative tiếp theo.
