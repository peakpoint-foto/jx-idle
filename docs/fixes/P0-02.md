# P0-02 — migration item cũ và stash

ID / trạng thái: code xong local; chờ fixture rương thật và nghiệm thu browser

Đã thực thi:

- `migrateCore` chuẩn hóa `mag`, `ext` trong `eq`, `inv`, `ground`.
- `stashRead` chuẩn hóa item khi đọc; `stashWrite` chuẩn hóa lần cuối khi ghi/import.
- Migration idempotent, giữ UID và các trường khác; save mới/migrate ghi `itemPolicyV=1`.
- Backup localStorage hiện tại của save/stash vẫn được giữ theo đường cũ; lỗi ghi trả về trạng thái lỗi và không commit tiếp transaction.
- `tagItem` áp policy cho item mới, bao gồm set/forge/shop/reward đi qua đường tạo item đó.

Ca chưa chạy: import file stash có item +38 trên Safari thật, localStorage đầy giữa transaction, UID trùng ở eq/inv/ground và đối chiếu số món/vàng trước–sau.
